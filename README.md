##  Running Locally

### 1. Clone the repository

```bash
git clone https://github.com/MikkyXCode/Ayomikun_Potfolio.git
```

### 2. Open the project

Open `index.html` in a modern web browser.

Because this is a front-end project, no backend installation or package manager is required for the basic version.
