SNACK-MAN

A browser-based arcade game inspired by the classic Pac-Man concept.

OVERVIEW

Snack-Man is a browser-based arcade game developed using HTML, CSS and JavaScript. The project combines interactive gameplay with front-end web development.

The aim of the project was to create an engaging game experience while developing practical skills in JavaScript programming, user interaction and game logic.

OBJECTIVE

The objective was to create a playable browser game that demonstrates how JavaScript can be used to control interactive elements and game mechanics.

TECHNOLOGIES

  • HTML
  • CSS
  • JavaScript

FEATURES

  • Interactive gameplay
  • Keyboard controls
  • Score tracking
  • Game logic
  • Browser-based interface

DEVELOPMENT

The game was developed using JavaScript to manage the gameplay logic and user interactions, with HTML providing the structure and CSS controlling the visual presentation.

The project provided an opportunity to practise organising multiple components of an interactive application and connecting user input with program logic.

CHALLENGES

One of the main challenges was managing the interaction between player movement, game rules and the browser environment. Developing the game required testing different behaviours and debugging JavaScript functionality.

WHAT I LEARNED

This project strengthened my understanding of JavaScript, event handling and interactive web development. It also helped me develop my problem-solving and debugging skills.

FUTURE IMPROVEMENTS

Future improvements could include additional levels, improved enemy behaviour, sound effects, animations and additional gameplay mechanics.
